Perfect play in a binary-scoring nonlocal game requires infinite dimension
Seth Douglas and Nidhal Mghirbi. Version 1.0.0, October 2026. A preprint; it has not been peer reviewed.

main.tex and references.bib are the manuscript sources.
paper.pdf is the compiled manuscript.
anc/ contains the complete game and reproducible finite checks.
arxiv/ is a standalone source package.

Build with standard pdfLaTeX and BibTeX:
  pdflatex main
  bibtex main
  pdflatex main
  pdflatex main

For a clean source tree, copy the source package elsewhere before building.
Use general local POVMs for the numerical dimension constants in the paper.
The matching logarithmic lower bound is an open problem.
