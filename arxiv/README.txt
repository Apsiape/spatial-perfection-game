Perfect play in a binary-scoring nonlocal game requires infinite dimension but only finite energy
Seth Douglas and Nidhal Mghirbi
Version 2.0.0, October 2026. A preprint; it has not been peer reviewed.

This folder is a standalone source package. Build from this folder:
  pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex
  bibtex main
  pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex
  pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex
The fresh bibliography is also supplied as main.bbl.
All proofs, bibliography databases and finite ancillary checks are included.
Run the ancillary checks with python -B anc/run.py --output <results-directory>.
Source and recorded-output checksums use LF line endings.
